MEAN
Auth Starter.

Registro, inicio de sesión y rutas protegidas con JWT sobre MongoDB, Express, Angular y Node.js. Contraseñas cifradas con bcrypt y tokens que expiran.

Probar la demoUsarlo en tu proyecto

Lo que incluye

Una base pequeña y clara para entender y reutilizar la autenticación con tokens.

01Registro e inicio de sesión

Endpoints /signup y /signin con validación de correo y contraseña.

02Contraseñas cifradas

bcrypt con 12 rondas. Nunca se guardan ni se devuelven en texto plano.

03JWT que expira

Firma con una clave en .env y vencimiento configurable.

04Rutas protegidas

Middleware verifyToken con mensajes claros para token vencido o inválido.

Pruébalo aquí

Crea una cuenta, inicia sesión y pide datos privados. En el modo simulado todo ocurre en tu navegador; en el modo API local se conecta a tu backend en localhost:3000.

Endpoints

GET/api/tasks—Datos públicos de ejemplo
GET/api/private-tasksBearerDatos privados de ejemplo

Úsalo en tu proyecto

1. Clona
git clone https://github.com/abixaiprin/mean-project
cd mean-project/backend
npm install
2. Configura
cp .env.example .env
# MONGODB_URI y JWT_SECRET
3. Ejecuta
npm run dev
# http://localhost:3000/api
